# She Style Backend API

Backend API for the She Style E-Commerce application.

## Tech Stack

- Node.js
- Express.js
- TypeScript
- Prisma ORM
- PostgreSQL
- JWT Authentication
- Swagger API Documentation

## Features

- User authentication
- Admin authorization
- Product management
- Category management
- Order management
- Inventory stock tracking
- Swagger API documentation

## Environment Variables

Create a `.env` file:

```env
DATABASE_URL=
JWT_SECRET=
PORT=
CLIENT_URL=
```

## Installation

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

## Build Project

```bash
npm run build
```

## Production Start

```bash
npm start
```

## Swagger Documentation

Available at:

```text
/api-docs
```

## Deployment

- Backend deployed on Render
- Database hosted on Neon PostgreSQL
