# She Style E-Commerce Project Documentation

## Project Overview

She Style is a full-stack e-commerce web application developed with separate frontend and backend architectures.

The application allows users to browse products, add items to cart, place orders, and manage purchases.  
An admin dashboard is included for managing products and monitoring customer orders.

---
